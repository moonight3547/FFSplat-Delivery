## 1. What was implemented (defaults off → delivery bit-identical)

`research/gsplat_depth_loss.py` — a PGSR single-view normal–depth consistency regularizer
that needs **ONE** extra gsplat 1.5.3 pass per application:

* per-Gaussian planar normal = world-space **smallest-scale axis** `R @ e_min` (PGSR's
  normal for a flattened Gaussian; the zero PLY normals from task-12 are not used);
* the extra pass renders that normal field as *colours* in `render_mode="RGB+ED"`, so
  **one pass yields both** the alpha-composited normal map (RGB) and the expected depth
  (ED) — no second pass for the normal map;
* `n_depth = normalize(cross(Sobel_x(D), Sobel_y(D)))`; on pixels with `alpha>0.5`,
  `D>0` and finite gradients, the loss is `mean(1 − |cos(n_depth, n_render)|)`.

`research/train_sweep.py` new flags (all default off): `--depth_reg_weight`,
`--depth_reg_every` (10), `--depth_reg_from` (4000), `--depth_reg_until` (5000); the
trainer record gains `depth_reg = {weight, every, from_iter, until_iter, events:[{iteration,
seconds, valid_fraction, depth_mean, normal_cos_mean}]}`. `research/run_sweep.py` passes the
flags through; driver arms `pgsr_sv10` (every 10) and `pgsr_sv5` (every 5), weight 0.2.

**Measured per-application cost** (`cost.json`, from `research/depth_cost_probe.py` on the
bicycle delivery PLY: 993,861 Gaussians, 576×960, after warm-up):

| item | value |
|---|---:|
| gsplat RGB forward / forward+backward | 1.953 / 7.470 ms |
| gsplat RGB+ED forward / forward+backward | 1.986 / **7.652 ms** |
| depth channel alone (extra) | +0.033 ms fwd / +0.182 ms fwd+bwd |
| one application (depth+normal, 1 pass) | **7.652 ms** |
| 4000–5000 every 10 (100 applications) | **+0.765 s B ⇒ TIME −0.180** |
| 4000–5000 every 5 (200 applications) | **+1.530 s B ⇒ TIME −0.361** |

So the financial bar is: **adopt only if Δq ≥ +0.5 on both DL3DV bad cases** (or Δtotal > 0
on both), per the task's verdict rule.
