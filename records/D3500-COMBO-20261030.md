## 4. Answers to the task's questions

**Does D3500+M1+cache beat D2500+M1+cache on total without losing >0.5 q?**
* **bicycle: NO** — 28.066 vs 28.127 (**−0.060**, a tie inside single-run noise; Δq +0.502
  in D3500's favour, ΔB +2.41 s against it). The combo gains are preserved at D3500
  (M1 −3.92 s B, cache −2.06 s B, quality unchanged within noise), but the base window's
  own cost eats the quality gain.
* **0b5635: marginally YES** — 36.744 vs 36.615 (**+0.129**, inside noise); D3500 alone
  (36.186) also beats D2500 alone (35.637) by +0.55 there, so this scene likes the longer
  window, but not by a margin that justifies a per-scene recipe.

**Is the extra structural work still worth it?** **No on the decisive bicycle case.** The
window buys +0.42 q (bicycle) / +0.72 q (0b5635) for +1.66 s / +0.89 s B → net total flat;
and it inflates N (1.72M vs 1.53M bicycle), which makes a future VGG100 tail (H1's next
step) more expensive per step. The clean conclusion is that **M1+cache are window-agnostic
B-recovery levers; the densification window itself is a flat trade between quality and
time**, so the cheaper window (D2500) is the better base.

**Cache behaviour at D3500 (Q3 from task‑19 re-checked):** scene_load 2.128 → **0.227 s**
(bicycle) and 3.698 → **0.272 s** (0b5635), i.e. the same 1.9–3.4 s saving; quality deltas
(−0.270 / −0.312) are inside single-run noise (N varies ±3 % run-to-run on this recipe).
Bundles were reused by version hash — **zero A-side rebuild cost** this time (the task‑19
strict 1‑ulp verify was relaxed to `transforms bitwise + pixels ≤1 ulp`, so no bogus
rebuild was triggered).

## 5. Caveats

* One run per arm (as tasked); q/N noise ≈ ±0.3 / ±3 %, so |Δtotal| < 0.3 (bicycle −0.060,
  0b5635 +0.129) is a tie, not a win. The unambiguous signal is that D3500's added quality
  is fully repaid by its added B.
* Absolute B is ~0.5–1.5 s above the clean‑13 session (GPU state); all arms are
  back-to-back on the same quiet GPU, so deltas are within-session comparisons.
* Bicycle LPIPS sits just above the 0.25 scoring cliff for every D3500 arm (0.2536–0.2598),
  so the quality term is PSNR+SSIM only — a 13-case run must confirm the cliff stays
  crossed; this is the same caveat as task‑19.
* VGG tail is out of scope here (H1 owns it); the recommendation above is about which base
  to hand to that tail.
