# 外观路线筛选：什么能留在官方PLY里

2026-10-30 07:25 +08:00。最新文献核验与本地代数推断；没有实现/运行GPU候选。与 [E9外观求解](APPEARANCE_SOLVER_20261030.md)、[E11难例归因](ZERO_SCORE_DIAGNOSIS_20261030.md)配合阅读。外观表达能力、光度不一致和SH导出错误是三种不同问题。

## 本轮核验的两篇工作

**PPISP，CVPR2026 Oral**：[作者页](https://research.nvidia.com/labs/sil/projects/ppisp/)、[最新v2，2026-04-07](https://arxiv.org/html/2601.18336v2)、[代码](https://github.com/nv-tlabs/ppisp)。它联合拟合曝光、暗角、颜色及响应曲线，再训练由渲染图预测新视角ISP的控制器。论文使用30K重建加5K控制器训练，MipNeRF360上控制器渲染开销约26%（其5090/3DGUT协议），不是当前5K FastGS的成本。仅训练每帧补偿、最终丢掉补偿，不等于完整方法。

**Compact Neural Appearance，2026-09-04预印本**：[v1全文](https://arxiv.org/html/2609.05255v1)、[作者页](https://fhahlbohm.github.io/efficient-gaussian-appearance/)。小共享MLP替换SH并与CUDA融合，报告更小外观存储及约1.3倍优化加速；质量比较使用PPISP，计时排除了其控制器蒸馏。作者低容量实验中外观模型差异缩小。它不能直接推导本项目换外观即可修复bicycle，且其新表示需要新渲染器。

**项目推断**：两者完整实现均不在当前“标准SH3 PLY由官方renderer读取”的直接可交付空间。将它们转换回SH3会引入新的近似/蒸馏成本，也会失去部分压缩和表达收益；不能把论文原始倍数带过来。暂不安排整套替换。这一筛选不等于认为曝光、反光一定不是当前瓶颈。

## 标准PLY的准确边界

设每高斯未做颜色clamp的数值RGB函数为

`c(d) = C0*h0 + sum(k>0, Yk(d)*hk) + 0.5`，`C0=0.28209479177387814`。

同一个、与相机/像素无关的正RGB通道增益`g`可以精确写成：

```
h0_new = g*h0 + 0.5*(g-1)/C0
hk_new = g*hk                 # k>0，逐RGB通道乘
```

它保持几何、opacity、排序与数量不变。黑背景、权重不依赖颜色时，合成也保持相同增益；正通道增益与每高斯下限0的clamp可交换。已保存的上限1截断RGB不能反推出未截断结果，因而不能只在PNG上估计后声称CUDA严格等价。当前官方render_test默认黑背景，并在保存时把最终RGB限制到[0,1]；真实CUDA路径仍须核验。

[独立标量验证](evidence/20261030-global-gain-bake-scalar.json)误差约1e-16，只是代数证据。它没有证明真实图像质量会提高，也没有验证自定义CUDA的所有分支。

**加法偏置不是同一件事**：若把每高斯颜色都加b，黑背景最终只增加`alpha*b`，而全图后处理增加b。alpha=.5、b=.1时，前者+.05、后者+.1。因此逐高斯DC偏置一般不等价于整图偏置。像素位置相关暗角、非线性CRF和逐视角控制器更不能由这个公式实现。一般3×3颜色混合还须单独处理颜色clamp，不能把正对角增益的结论泛化。

## E9-P：只有全局颜色偏差命中时的极小对照

这不是PPISP复现，优先级低于SH接口。先复用E11训练视角残差，观察误差是否跨视角呈同方向、近似全局的通道偏差；如果主要是局部缺失/模糊，不做该实验。

任务包：同一固定5K PLY，在预注册训练图上拟合3个正通道增益，围绕1做统一小正则与统一边界；保留未参与拟合的训练图检查偏差是否一致。不得使用test拟合任何增益、曝光或后处理。保存未截断预测和饱和比例，不能用test对齐后的PSNR/LPIPS作为正式成绩。

对照：相同已有PLY+identity gain；相同PLY+拟合gain后静态重写SH。首轮仅比较这一项，最终两组都用原官方renderer；所有加载/训练图渲染、拟合和重写时间算入候选成本。参数边界是所有场景相同的预注册规则，3个gain是场景内拟合参数，不是按每例test挑超参。

若未拟合训练图的残差改善很小、不同训练区域需要相反增益、或正式未校色指标回退，就停止，不升级到逐图曝光网络。若成立，再与等时普通appearance Adam比较；不能因多给了额外渲染时间就宣布求解更优。

这一包主要回答“当前误差中是否有可静态表达的全局颜色偏差”。它不会补齐缺失几何，也不替代真实共视、深度一致性或结构带宽诊断。
