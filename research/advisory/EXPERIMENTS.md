# 大颗粒实验方案

方案日期：2026-10-30。所有新增方法均未在本轮实现或运行。实验交给 coding agent。以下参数是预注册起点，不是论文原参数或预测最优值。

## 共同基线与裁决规则

**06:10控制组修订**：后续 C 统一指 C_raw = **未做opacity锐化的原始ReSplat初始化** + FastGS5K、位置LR长度5K、无reset、DSSIM .6、scaling LR .01、结构截止1250。历史锐化h1-delivery另记 C_sharp；其指标不替代新C_raw对照。先同步新配方原始记录并锁定run identity。

**06:31衔接**：当前入口又增加image cache。每个新实验应使用相同缓存设置的C_raw控制，首次cache成本单列并计入E2E；无cache历史控制不直接与有cache候选做时间归因。新增SH导出问题的F0–F2先见 [决策板](DECISION_BOARD.md)，E6–E9在专门文件中细化，不要求同时实施。

相同代码/依赖/GPU UUID、prepared input、训练/测试划分、seed 和最终官方渲染。默认三例，单卡串行、无并发；控制和候选交错顺序运行，失败或超预算 case 保留，不从完整集合均值删除。

先处理 CODING_NOTES 的计时问题。记录 A、R、B、E2E 和各自进程墙钟；预处理、先验提取、统计预计算、读写、导出都不免费。评价成本另列，不能混入候选而不混入参考。参考仍是同卡同输入随机 FastGS30K。

固定三例上的方法研发可以用 held-out 指标作离线评价，但 test RGB 不进入候选执行过程；不按每场景最佳 test checkpoint 交付。不用 quick test PSNR 决定停止、采样、阈值或变体。先注册统一策略，后统一评分。

第一阶段只比较同 5K 步，确定机制是否改善；第二阶段对幸存方法做同总时间对照（包括其新增开销，LR 随实际计划优化进度衰减），防止用更贵步骤制造假提升。取固定协议的最终 PLY 评估。若做质量-时间曲线，只用于离线解释，不逐 case 选择交付步数。

筛选建议：三例平均净代理增益不足 +1 或任一 case 质量降幅 >1 分，先判低优先；不是立即扩展。最终采纳按旧研究门槛要求重复测量后三例均值净增益 ≥+2、没有超预算，并通过后续确认场景。门槛是研发决策规则，不是显著性检验。重复时报告 paired delta 和范围，不能用一个 pooled 均值掩盖回退。13 例仅在现有任务授权与资源允许时由 coding agent 执行，本目录不触发。

**06:35门槛细化**：上述+1/+2是较重算法路线的投入筛选参考，不是所有改进的硬性准入条件。低成本fused执行后端、像素等价IO复用，以及数学接口正确性修复，应按可重复净收益、质量回退和维护成本分别判断；不能因最多省0.5分就否定几行可维护的系统优化，也不能要求一个正确性修复先涨2分才处理。每项仍须计入真实成本并保留控制。

分数换算帮助决策：在线性有效区，额外一秒约损失 `20/(0.9*Tbudget)`，当前约 0.22–0.24 分；LPIPS 降低 0.01 约增 2 分（未触发 clip）。它是成本门槛，不是预期收益。

## E0 — 先测清瓶颈，再决定优化 IO 还是计算

**问题**：交付 DL3DV/counter 的 scene load 为 11.009/8.873 秒，B 优化本体约 25 秒；理论上缩短加载值得研究，但不能把预加载搬到 A 便称提速。

**任务包**：C 不变，仅拆出 decode、CPU→GPU、PLY load、优化、统计 pass、真实 export 和 evaluation。冷启动和持久进程各测各报；最终按提交接口的实际运行方式验收。若提出 uint8 cache/延迟 decode，验证处理后图像张量与原路径一致，且 5K 步访问视角集合不变。

**止损**：占比很小就不做 IO 改造；如果只是改变计时边界、把加载转移到前一阶段，判无效。成功后把这条系统优化固定到所有方法和其新参考，不能只给候选用隐含热缓存。

**价值**：这是测量与系统建议，不算新的学术方法。

## E1 — 结构感知的少量定向分裂（首选 B 方案）

**科学假设**：ReSplat 的部分高斯投影过宽，覆盖的局部纹理频率过高；普通位置梯度不能区分几何错位和带宽不足。按高频方向一次性细分，比盲目增长更可能在短跑保留细节。文献机制：[SAD-GS](https://arxiv.org/html/2604.28016v1)。

**大颗粒实现边界**：训练图预计算低成本多尺度结构/频率图；在前 1250 步收集可见高斯的投影尺度与局部频率不匹配，只对跨多个训练视角稳定不匹配者定向分裂。保留统一 5K LR 和 loss，结构阶段结束后稳定拟合。首版不引入论文的其他 loss、场景包围盒新点或整套新 renderer。

**最小对照**：C；C + 定向分裂；C + 相同分裂次数/子高斯数的普通分裂。三组统一限制峰值数量相对初始化最多 1.25 倍，新增分裂预算不超过初始化数量的 10%（两者都是本地预注册上限）。若不能使数量完全配平，记录差值，不能归因于方向选择。

**观察量**：高频区域训练残差、最终 PSNR/SSIM/VGG-LPIPS、每次结构操作耗时、峰值/最终 N、投影足迹或 tile 交叠代理量。既要区分“选中对象正确”，也要区分“仅因为点更多”。

**止损**：没有多视角稳定的带宽违例，或候选与等数量普通分裂无差别，就不继续调阈值；若需要整套 CUDA 移植才能拿到统计，先评估工作量，降级为后续工程路线。高斯数增加但同总时间不增质量，关闭。

**证据边界**：这不是过去“更低 densify 门槛/900K 上限”的重跑；也不是论文原版复现。作者代码依赖新扩展，不能承诺即插即用。

## E2 — 真实表面覆盖与共视连通的 16 图选择（A 方案）

**依赖**：先收回现有 `selection_test.sh` 的 uniform/fps/coverage 完整结果。不要重写已在跑的实验，也不要仅凭 B=0 排名选赢家。

**科学假设**：相机位置 FPS 会选出朝向错误或重叠很少的视角；当前 coverage 用相机包围盒，可能奖励看见空体素。已有 SfM 轨迹的表面覆盖加共视连通更贴近匹配与前馈要求。相关机制：[Z-Order 选图](https://arxiv.org/html/2605.13465v1)。

**任务包**：从已有 COLMAP 点/观测构建 view–track 二部图。只用训练观测，轨迹需至少两张训练图支持；按可靠性、表面栅格均衡和视角夹角贡献加权。贪心增加覆盖，同时要求新图与已选图有共视边，防止选集碎裂；覆盖收益对同点的观测次数饱和，避免全部看向同一区域。输出固定 16 张，仍按 train 顺序送入 ReSplat，不移动 pivot 约定。

**最小对照**：uniform；现有 coverage；新图策略。每组一次相同 ReSplat + 相同 C。轨迹不足或图不连通时使用事先规定的 uniform 回退并报告；不为不同场景指定另一个阈值。不得为覆盖预计算跑第二次 ReSplat。

**观察量**：训练轨迹覆盖、至少双视角支撑占比、选图图连通分量、baseline 角度分布、A 耗时、B=0 和最终质量。单图新增覆盖很高但共视支撑下降是失败征兆。

**止损**：最终而非初始化质量没有提升，或 A 开销抵消收益，关闭；与 uniform 选中集合相同只说明这次策略无效，不能称已验证新选图机制。输入稀疏文件没有真实轨迹时暂停该方案，不用虚构 tracks。

## E3 — 只在需要修复且先验可靠的区域使用深度

**科学假设**：ReSplat 深度与初始化同源，全图约束容易锁死原有错误；但可信多视角区域可稳定欠约束局部。相关机制：[In Depth We Trust](https://arxiv.org/html/2604.05715v1)。

**先决检查**：同一次前馈拿到 depth sidecar；确认 camera-Z/射线距离、内参/裁剪、场景尺度、名称与 context 对齐。先在真实 GPU 验证编码渲染的 depth 与 alpha 数值。不能用重渲染初始化深度冒充独立预测，不能额外一次 ReSplat 推理后不计时间。

**任务包**：M_prior：预测深度在已有相邻 context 上通过前后重投影检查、遮挡剔除；M_need：当前模型的训练残差较高或几何一致性不足。只在二者交集做稳健弱深度/相对梯度约束。二者不能共用同一个“深度不一致”定义：先验不一致意味着不可信，模型不一致才意味着待修复。

**最小对照**：原 C；全图弱深度；双掩码深度。权重统一 0.05，每 4 步监督一次，启用区间为总步数 25%–75%，pose LR 固定 0；这些为本地起点。先复用已实现路径，只增加掩码逻辑，不叠加新法向项。训练时只有 16 context 有先验，记录 supervised_steps/total_steps，不把目标频率误称实际监督覆盖率。

**观察量**：两个掩码及交集比例、每场景有效监督次数、深度 loss 开销、floater/重投影误差和最终质量。没有 GT 几何时，一致性仅作诊断，不宣称几何精度提升。

**止损**：单位/alpha 检查失败立即停止；有效区域近乎为空时报告先验无覆盖，不强行松阈值；全图与掩码均未还回额外计算成本，不追加 pose 调参。

## E4 — 按渲染贡献与误差联合重分配容量（备选）

**科学假设**：少量低贡献高斯占用计算，纯 opacity/scale 剪枝却会误删背景。用贡献保护与误差引导协同，可能在不增加 N 的条件下把容量移到缺细节的区域。相关机制：[2026-10 confidence-aware densification](https://arxiv.org/html/2610.13541v1)、[贡献感知 ADC](https://arxiv.org/html/2503.14274v1)。

**任务包**：首版只在结构阶段结束前进行一次重分配，低多视角累计贡献者让位给高训练误差、有多视角表面支撑者；保护远背景和薄结构的最低可见支持，保持 N 和 C 接近。不要以 opacity 单独打分，不添加完整 MCMC 噪声/relocation 日程，不引入新全局模型。原论文的逐高斯 confidence 可以是场景参数，但首版先不用它。

**最小对照**：C；只有贡献剪枝；贡献剪枝 + 误差引导替换。固定迁移比例 5%、时点 1000 步。重新初始化的 optimizer moments/SH/scale 需明示。新增统计 pass 全计时，不能拿普通 rasterizer 不存在的 per-Gaussian blending weight 当已有接口。

**止损**：拿不到可信贡献统计而需要大改 rasterizer，或替换后尚未收敛已到截止时间，降级；剪枝节省不了真实步耗时，且最终质量下降，关闭。它与旧预剪实验的区别必须由保护机制和等数量对照证明。

## E5 — 训练视角的残差与 age 调度（低成本备选）

**科学假设**：5K 步里均匀遍历可能把过多更新给已拟合图；适度把更新给欠拟合且久未访问的训练图，可改善每秒质量。借鉴 [TurboGS](https://arxiv.org/abs/2606.15924) 的误差/age 计算分配思想，方案本身是 camera-level 本地假设。

**任务包**：维护每张训练图最近光度/结构残差的 EMA 和 age，只利用实际访问时已有 loss，不额外全图评价。保持每轮所有训练图至少访问一次；其他步骤用固定混合 `0.5 uniform + 0.5 residual/age`，对异常最高残差截断，防止反光/动态区域独占。末 25% 退回 uniform 稳定收敛。所有场景一套规则。

**最小对照**：C 原随机无放回；仅 age 公平调度；残差+age。相同 5K 步后再做同时间验证。报告每图访问分布、最大未访问间隔和训练开销。

**止损**：高残差视角持续不降、尾部视角饿死或 held-out 质量回退，就关闭。完整渲染后 mask 不算加速，不对这条方案引用 TurboGS 的速度倍数。

## 推荐执行顺序与结果回填

E0/计时核查 → 读取已有 A/depth/eval13 结果 → E1 与最小对照 → E2 或 E3（按已有结果是否支持继续）→ E4/E5 备选。每轮只改变一种机制；只对幸存单项做一次组合，防止失败归因不明。

结果放 `research/advisory/results/<日期>-<E编号>.md`，原始训练记录仍按项目约定放 records。回填最少包含：假设、实际代码提交、数据与 GPU 身份、对照、统一参数、完整 case 列表、实际分项耗时、原始指标、两种时间范围的代理分及有效性、paired delta、额外开销、失败/缺失 case 和继续/停止裁决。没有运行则明确写未运行。
