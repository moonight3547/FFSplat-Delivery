# 优化器与梯度支撑：新方案筛选

检索：2026-10-30 05:53–05:55 +08:00。只做文献与实验设计，不实现优化器。

## 1. 二阶法不能只比迭代数

[3DGS²-TR 预印本](https://arxiv.org/abs/2602.00395)、[作者 PDF](https://lavaei.ieor.berkeley.edu/3DGS_2026_1.pdf)、[公开实现](https://github.com/rogerhh/3dgs2-tr)研究对角曲率与 Hellinger 距离信赖域。其固定初始化、无致密化设置与本项目后期有相关性；论文也报告 ADAM-TR 对照能改善质量。但作者承认当前实现每步较慢，完整二阶版需要 forward-mode CUDA，尚不能根据“少50%迭代”推断更快。论文的理论 O(n) 是渐近复杂度，不是与现有 fused FastGS 的每步成本相等。

迁移判断：完整二阶版暂不优先；抽出“限制几何单步变化”的轻量实验。它与把参数拉回初始化的 L2 anchor 不同，也与逐训练相机平移微调不同。

[LM-RS，3DV 2026](https://vcai.mpi-inf.mpg.de/projects/LM-RS/)、[官方代码](https://github.com/hamzapehlivan/lm-rs)给出 matrix-free LM 与残差采样，低高斯数量和中等数量的收益不同，依赖专用 JVP CUDA。相比 [3DGS-LM，ICCV2025](https://arxiv.org/abs/2409.12892)，这说明二阶研究并非只有旧版20%收益。但它们对原始 Adam 的速度倍数，不是对当前 FastGS 的倍数；也不能把小规模结果套用到40–50万高斯。

本地成本估算：当前优化本体约25秒，若只把它提速1.3倍，最多省约5.77秒，在线性 TIME 区约值1.3分；加载/导出不受影响。这是估算，不是性能预测。若实现成本很高，优先做低成本几何约束或结构方法。

## 2. 新增 E6：后期局部尺度归一化的单步约束

**假设**：已经接近表面的前馈初始化，在短程后期仍可能因少量异常几何更新改变遮挡和透射，拖慢稳定收敛。限制每步几何变化可能更有效地使用后期预算。

**控制**：最新 raw 初始化、统一5K配方；先读回 raw/sharp A/B 原始记录并明确控制 ID。结构阶段仍截止1250。

**干预**：仅在结构阶段结束后对 proposed mean update 做当前高斯局部尺度归一化的限幅，同时可设固定 log-scale 更新上限；颜色/SH 更新不变，不加渲染 pass。第一次只试一个统一预注册上限，例如局部归一化 mean-step 范数0.05、log-scale step0.02。这些是本地探索值，不是论文参数，也不保证是最优。

**对照三组**：C；相同量级的世界坐标统一限幅；局部尺度归一化限幅。后两组使用同样日志与复制开销，比较“有clip”和“按高斯几何缩放clip”。若预算只允许两组，先 C vs 局部约束，成功后补世界尺度对照。

**必要记录**：每步被限幅比例、归一化更新分位数、训练 loss、最终指标和增加的 GPU/墙钟时间。需要在不影响优化器状态索引的情况下处理 topology；故首版放到固定拓扑后期，不在 split 当步改动。

**边界**：这个简化方案不等于原文完整 Hellinger bound；多个参数同时更新时，分别限幅不自动保证整体分布距离有严格上界。不得把经验 clip 描述成理论保证或原论文复现。

**止损**：实际几乎从不限幅，说明没有命中假设，关闭；持续大量限幅且训练残差下降变慢，则它压制了必要运动，关闭。额外开销吃掉净收益也关闭。只有出现稳定净增益才研究完整 ADAM-TR，暂不迁移 Hessian/JVP 栈。

## 3. 新梯度支撑工作：更稳并不一定更省

[TruncGradGS，Pacific Graphics 2026](https://arxiv.org/html/2609.03534v1)扩大弱/失活高斯的有效梯度支撑，并配合延迟剪枝；论文明确指出通常会增加训练时间，且把代理梯度施加给全部高斯可能使优化发散。它对“低opacity不一定没用”提供机制层面提醒，但不是本项目现成加速插件。

首轮不移植截断梯度 kernel。若 E1-D 发现高残差区域根本没有有贡献的高斯支撑、而非现有高斯投影太宽，则它属于“支撑缺失/梯度到不了”的另一类问题，应考虑有几何证据的小范围重分配；不能继续往原高斯周围盲目分裂。新的数据集或动态表示不进入本任务。

## 4. 10月新工作：位姿问题的最新进展与适用边界

[SG-Splat，2026-10-26 预印本](https://arxiv.org/abs/2610.35361)联合几何/属性分支、光流相关与可微 BA，并采用训练策略改善 pose uncertainty。它改变模型与训练，不是固定 ReSplat 后可直接调用的模块；本轮未核验公开可用权重，不围绕它排复现实验。可借的诊断原则是分开几何错配和外观误差，不能由单纯调相机平移无效就断言几何已完全正确。

## 5. 与正在新增的 MCMC 试验对齐

控制端出现 `campaign_mcmc.sh`、`mcmc_compare.sh`，说明 coding agent 已安排新的有墙钟预算的 MCMC 对照。本研究不重复启动。

建议确保：与 FastGS 比较时 raw 初始化和输入相同；逐例 reference budget 与40/80秒训练allocation分开；报告实际 total_seconds而非分配上限。第一轮包含 CTF/cap/优化器多个变化，只能回答“整体候选是否更好”，不能单独归因 MCMC。若整体失败，仅在训练曲线有明确信号时补 full-resolution 对照，不无限增加网格。

名称也需分清：MCMC 与 Taming-3DGS 不是同一种方法。以上是可解释性要求，不干预已运行作业。
