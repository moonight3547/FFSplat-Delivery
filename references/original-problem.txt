一、题目名称：前馈亲和的3DGS重建质量提升算法
决赛赛题名称：前馈亲和的3DGS重建质量提升算法
决赛赛题来自技术领域：图形
决赛赛题题目澄清人： 郭俊甫 00949224
赛题限制：本赛题可面向高校/开源社区/海外研究所外部揭榜。赛题数据集为合成或脱敏数据，不涉及业务保密限制。推荐参赛者自备高性能PC验证。
二、背景信息（赛题产生的业务背景）：
传统3DGS（3D Gaussian Splatting）为分钟级重建速度。现有的前馈式重建方法，如ReSplat等，只需输入8~16张带位姿的图片，网络便可在秒级时间内直接完成场景重建，但受限于网络容量与训练数据分布，在复杂场景、细节纹理、多视角一致性上存在质量差距，即使将前馈重建方法导出的结果，使用传统重建方法接续重建一段时间，结果的重建质量依然难以超过传统重建方法。因此，这种依靠模型的快速重建方式，在落地过程中往往面对质量难以提升等问题。严重影响AR预览、商品3D展示、数字孪生等场景的用户体验，限制了3DGS技术的实用化落地。
三、问题描述（现状、技术挑战等）：
3.1 问题现状
现有的前馈式重建方法（以Resplat为例），虽然可以达到少量视角输入，秒级出图，然而却面临质量低于传统3DGS重建质量的瓶颈。希望参赛选手，通过对于Resplat进行插件式处理，依赖前处理和后处理的方法，在不超过经典重建算法的时间内，达到更高的重建质量。
需要特别说明的是， 本赛题的重点在于前馈方法的前处理和后处理算法，并非着眼于修改前馈算法本身，因此不需要选手对前馈模型本身进行额外调整。                                                                                                                                                                      

  3.2 问题拆解
选手需要围绕Resplat增加如下两个模块：
1. 前馈网络的输入视角选取与其他预处理方法（模块A）
2. 前馈网络与优化质量的平衡（模块B）

最终期望达成在同等质量下，端到端总耗时（筛帧 + ReSplat + 接续）接近"半分钟级"的实用水准。

  3.3 问题抽象
本难题本质是如何使用前处理加后处理的方法在不造成性能过度劣化的情况下，提升前馈模型的生成质量。前馈模型是给定的，不能重新训练或替换的。参赛者需要在不修改模型的前提下，提出有效提升质量的插件式前处理和后处理方法。
  核心是找到前馈模型导致重建结果质量下降的根本原因，并提出有效的方法进行针对性解决。
3.4 接口定义

  输入：3DGS训练数据集（多视角图片+相机位姿）；基座模型：ReSplat 官方代码仓库与预训练权重（赛题方提供固定commit 与权重）。

  输出：重建后得到的3DGS模型（PLY格式）+ 渲染结果图像（PNG）+ 性能与质量报告。

  3.5 约束条件

选手自备高性能PC即可（推荐RTX3090及以上显卡）。
1. ReSplat 本体（网络结构、预训练权重、前向推理过程）不得做任何修改，只能当作黑盒调用。
2. 模块 B 的运行时间必须严格小于经典 3DGS 从零训练 30000 轮所需的时间。考虑到选手硬件型号不同，时间预算不采用绝对秒数，而采用等效轮数：选手需在自己机器上先实测经典 3DGS 单轮迭代耗时 T_iter，则模块 B 的允许时长为 30000 × T_iter。（比赛评审时按官方基准机同样规则复测。）
3. 不允许任何形式的"人工逐场景调参"——所有超参数必须跨测试场景统一。
4. 提供一键运行脚本：`python run_pipeline.py --scene <场景路径> --output <输出路径>`；
注：后期验收测试会使用另外数据集进行测试。

六、参考文献（可选，如有请提供）：
核心论文与代码：
1. ReSplat: Learning Recurrent Gaussian Splatting（arXiv: 2510.08575，ECCV 2026）——赛题基座，其以渲染误差为反馈信号、用共享权重的递归网络做无梯度迭代细化，在 DL3DV、RealEstate10K、ACID 等数据集上达到前馈方法的 SOTA。 代码：https://github.com/cvg/resplat
2. Kerbl et al., *3D Gaussian Splatting for Real-Time Radiance Field Rendering*（SIGGRAPH 2023）——经典 3DGS，质量金线与时间基准。
3. Chen et al., *MVSplat: Efficient 3D Gaussian Splatting from Sparse Multi-View Images*（ECCV 2024）；Xu et al., *DepthSplat*（CVPR 2025）——前馈高斯的代表工作，理解其局限有助于定位质量差距来源。
4. Chen et al., *SplatFormer*——针对已优化 3DGS 的单步细化网络，可作为"高斯后处理"思路的参考（注意其为非递归、面向物体级场景的设计）。
开源数据集：
- Mip-NeRF 360（无界 360° 场景，9 场景）：http://storage.googleapis.com/gresearch/refraw360/360_v2.zip
- LLFF（前向场景）：https://github.com/Fyusion/LLFF
- Tanks and Temples：https://www.tanksandtemples.org/
- DL3DV-10K（大规模真实场景视频，含位姿标注）：https://github.com/DL3DV-10K/Dataset
- Deep Blending（自由视点室内场景）：http://storage.googleapis.com/gresearch/refraw360/tandt_db.zip
